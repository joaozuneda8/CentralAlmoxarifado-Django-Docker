**Goal:** Projeto Django rodando sobre MySQL/MariaDB, com settings lidos do `.env`, login por
matrícula, os dois layouts da interface (almoxarifado e público) e o admin dos cadastros
mantidos à mão (itens de limpeza, centros de custo e opções).

**Architecture:** Um único módulo de settings (`config/settings.py`) lê o `.env` com
`python-dotenv` e liga as proteções de produção quando `DEBUG` está desligado. Um usuário
próprio (`contas.Usuario`, `AbstractUser` com o `username` rotulado "matrícula") nasce na
primeira migration. O app `interface` recebe, copiados do WMS-Almoxarifado, tokens/base/
components CSS, `shell.js`, HTMX 4.0.0 e as parciais; sobre eles ficam `base_publico.html` e
`base_almoxarifado.html`. `catalogo` ganha os modelos que o admin edita (e `Material`, que o
`ItemLimpeza` referencia); `pedidos` ganha a página inicial pública, o painel (ainda vazio) e o
começo de `regras.py`.

**Tech Stack:** Python 3.13, Django 6.x, uv, mysqlclient, python-dotenv, whitenoise, waitress,
pytest + pytest-django, ruff.

**Spec:** `docs/superpowers/specs/2026-10-10-central-almoxarifado-django-design.md` (seções 2, 3,
8 e 9 item 1).

**Fonte da fundação visual:** repositório `joaorighetto/WMS-Almoxarifado`, commit
`70798439575da9d51547b0bc585b6a783b2e524c`. Para copiar:
`gh repo clone joaorighetto/WMS-Almoxarifado <pasta-temporária> -- --depth 1` e conferir o commit
com `git -C <pasta> log -1 --format=%H`. Daqui em diante, `WMS:` indica um caminho nesse clone.

## Global Constraints

- `requires-python = ">=3.13,<3.14"`; Django `>=6.0,<7`; dependências só via `uv` (`uv add`), com `uv.lock` versionado.
- Banco: MySQL 8 ou MariaDB com `mysqlclient`, charset `utf8mb4`. Os testes rodam contra MySQL/MariaDB, nunca SQLite.
- Sem npm, bundler ou CDN. HTMX 4.0.0 vendorizado em `interface/static/interface/vendor/htmx/`.
- Segredos só no `.env` (fora do git); `.env.example` versionado com todas as chaves, sem valores reais. `DEBUG` desligado em produção.
- Textos de interface, mensagens e nomes de código em português (pt-BR), como no WMS-Almoxarifado.
- Regras do `DESIGN.md` do WMS-Almoxarifado: um accent azul; estado nunca só por cor; códigos em fonte mono (`.mono`); tabelas com rolagem lateral no celular.
- Logout só por POST com CSRF, num único formulário por página. Requisições HTMX que gravam vão dentro de um `<form>` com `{% csrf_token %}`.
- Arquivos copiados do WMS-Almoxarifado mantêm o aviso MIT do django-observatory em `THIRD-PARTY-NOTICES.md`.
- `ruff` com `line-length = 100`, `target-version = "py313"`, `select = ["E", "F", "W", "I", "UP", "B"]`, migrations excluídas.
- Toda mensagem de commit termina com a linha `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Recusa de login em pt-BR com erro de concordância.** A tradução do Django gera "entre com um matrícula"; a pessoa deve ler uma frase correta e genérica ("Matrícula ou senha incorretas."). Teste na Tarefa 3.
2. **`next` apontando para outro site.** Um link de login com `?next=https://outro.site` não pode levar a pessoa para fora do sistema depois de entrar. Teste na Tarefa 3.
3. **Produção atrás do Apache.** Com HTTPS terminado no Apache e `SECURE_SSL_REDIRECT` ligado, sem `SECURE_PROXY_SSL_HEADER` a página entra em redirecionamento infinito. `PROXY_HTTPS=1` deve ligar o cabeçalho. Teste na Tarefa 1.
4. **Placa digitada em outro formato.** "cza-1614" num centro de custo e "CZA1614" em outro são a mesma placa; o admin deve recusar a segunda, porque o robô não saberia qual centro usar. Teste na Tarefa 4.
5. **Texto com acento e emoji.** Nomes com "ç", "ã" ou emoji (copiados de mensagens) devem gravar e voltar iguais; um banco em `utf8` de 3 bytes falharia. Teste na Tarefa 1.

def rodar(args, **env):
    """Roda `python <args>` na raiz com config.settings (o pytest exporta settings_test)."""
    ambiente = {**os.environ, "DJANGO_SETTINGS_MODULE": "config.settings", **env}
    return subprocess.run(

        capture_output=True, text=True, timeout=120,

@pytest.mark.parametrize(
    ("valor", "esperado"),

     ("0", False), ("false", False), ("nao", False), ("não", False), ("off", False)],
)
def test_ler_bool_reconhece_valores(monkeypatch, valor, esperado):
    monkeypatch.setenv("X_TESTE", valor)
    assert ler_bool("X_TESTE", not esperado) is esperado


@pytest.mark.parametrize("valor", [None, "", "  "])
def test_ler_bool_vazio_usa_padrao(monkeypatch, valor):
    if valor is None:
        monkeypatch.delenv("X_TESTE", raising=False)
    else:
        monkeypatch.setenv("X_TESTE", valor)
    assert ler_bool("X_TESTE", True) is True


def test_ler_bool_valor_invalido_recusa_com_o_nome(monkeypatch):
    monkeypatch.setenv("X_TESTE", "talvez")
    with pytest.raises(ImproperlyConfigured, match="X_TESTE"):
        ler_bool("X_TESTE", False)


def test_ler_lista(monkeypatch):
    monkeypatch.setenv("X_TESTE", " a.com, b.com ,, ")
    assert ler_lista("X_TESTE") == ["a.com", "b.com"]
    monkeypatch.delenv("X_TESTE")
